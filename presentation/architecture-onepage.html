Design system

Metallic black surfaces with cool silver sheen; accent orange #f97316 (buttons, highlights). Circular venue logo only — no text under logo. Guest shell max-width phone layout; staff screens landscape-friendly.

Typography: Cairo (UI) · Fraunces (display) · full RTL for Arabic & Hebrew.

Languages

Guest + staff UI order:

1 · ar Arabic 2 · he Hebrew 3 · en English 4 · ru Russian

  • Guest: language picker → registration switcher
  • Menu / item text via next-intl + DB translations
  • Staff apps: Kitchen · Waiter · Admin switchers
  • Admin menu edit locale independent of UI lang

Request flow (happy path)

NFC/QR → language → register (terms + table password) → browse menu → cart → POST /api/v1/tables/:token/orders → kitchen ticket by MenuItem.route → waiter serves / cash-card → tip → close session · live updates via SSE to guest & staff.
